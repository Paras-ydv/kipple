# Security policy

kipple deletes files, so safety bugs are security bugs. This includes any case where kipple marks something `Safe` that is not, touches a protected location, or modifies anything without confirmation.

## Reporting

Please report privately through [GitHub security advisories](https://github.com/Paras-ydv/kipple/security/advisories/new). Do not open a public issue.

Include the kipple version, your OS, what happened, and the output of `kipple explain <item>` if relevant. Never attach real session files, databases or anything with personal data.

We aim to reply within 7 days.

## Supported versions

Only the latest release receives fixes while kipple is pre-1.0.
