# Labels

| Label | Use |
|---|---|
| `safety` | Anything that could remove data it shouldn't. Highest priority. |
| `bug` | Something does not work as described. |
| `integration` | New integration or a change to one. |
| `good first issue` | Small, well-described, good for newcomers. |
| `platform:macos` | macOS-specific. |
| `platform:linux` | Linux-specific. |
| `platform:windows` | Windows-specific. |
| `platform:wsl` | WSL-specific. |
| `ui` | TUI, desktop app or share card. |
| `docs` | Documentation. |
